Valve Decoder

A Python application that turns FlowSafe's historical PDF pick-sheets into a structured, searchable engineering database.

See Experience Download resume

Role: Industrial Engineering Intern  ·  FlowSafe / Dresser Utility Solutions  ·  Continuing during the academic semester

Problem

FlowSafe's historical shipped-valve records existed only as PDF pick-sheets — a format that's fine for a single job, but effectively unusable as a data source once you need to search, aggregate, or analyze across thousands of them.

Why it mattered

The facility material-flow analysis needed reliable historical valve-shipment data to calculate accurate travel-path frequencies between facility locations. That data existed, but it was locked inside thousands of individual PDF documents with no structured or searchable form — directly blocking the facility study until a real dataset existed.

Constraints

  • No clean structured export of the historical pick-sheet data existed — only the original PDFs.
  • The extracted data needed to be accurate enough to support a real quantitative analysis, not just a rough approximation.
  • Needed to be general enough to stay useful as a reference tool after the immediate need (the facility study) was done.

My role

I built the Valve Decoder independently as my project during my Industrial Engineering internship at FlowSafe / Dresser Utility Solutions.

Data & engineering approach

  • Built a Python application to parse historical PDF pick-sheets and extract structured records.
  • Processed 19,567 shipped-valve records covering 1,951 unique valve models.
  • Structured the extracted data into a searchable database, rather than a one-off export.

Development process

I built the PDF-parsing and data-extraction pipeline first, validated the extracted records for accuracy against the source documents, then structured the output into a searchable database — usable both for the immediate facility material-flow analysis and as a standalone engineering reference tool afterward.

Solution

A Python application that converts FlowSafe's historical PDF pick-sheets into a structured, searchable database of shipped-valve records — closing the data gap that was blocking the facility material-flow study, and outliving that original purpose as a reusable production/engineering reference tool.
